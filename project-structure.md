# Online24 Pharmacy - Complete Project Directory Structure

## Root Directory Files

### Configuration Files

- **`.env`** - Environment variables for production (contains sensitive data like database URLs, JWT secrets, API keys)
- **`.env.example`** - Template file showing required environment variables without sensitive values
- **`.gitignore`** - Git ignore rules to exclude sensitive files, node_modules, build artifacts, and temporary files
- **`.npmrc`** - NPM configuration file for package registry settings
- **`eslint.config.js`** - ESLint configuration for code linting and style enforcement
- **`package.json`** - NPM package configuration with dependencies, scripts, and project metadata
- **`package-lock.json`** - Lockfile ensuring consistent dependency installation across environments
- **`postcss.config.js`** - PostCSS configuration for CSS processing and Tailwind CSS
- **`tailwind.config.js`** - Tailwind CSS configuration with custom theme, colors, and responsive breakpoints
- **`vite.config.js`** - Vite build tool configuration for development server, proxy settings, and build optimization
- **`vitest.config.js`** - Vitest testing framework configuration
- **`yarn.lock`** - Yarn lockfile for dependency version locking

### Documentation Files

- **`DATABASE_DESIGN_DOCUMENTATION.md`** - Database schema design, relationships, and data flow documentation
- **`DATABASE_WORKFLOW.md`** - Database operations workflow and maintenance procedures
- **`ONLINE24_PHARMACY_PRESENTATION.md`** - Project presentation slides and overview documentation
- **`README.md`** - Project overview, setup instructions, and usage guide
- **`doc.md`** - Comprehensive technical documentation (created in previous session)

### Application Entry Points

- **`index.html`** - Main HTML template for the React application
- **`server/index.js`** - Main Express.js server entry point

### Utility Scripts

- **`check-models.js`** - Script to validate and check database models
- **`create-placeholder-images.js`** - Script to generate placeholder images for development
- **`update-product-images.sql`** - SQL script for updating product image references in database

## `/data/` Directory

Contains static data files used for seeding or testing:

- **`users.json`** - Sample user data for development and testing purposes

## `/dist/` Directory

Build output directory (generated by Vite):

- Contains compiled and optimized production assets
- Includes bundled JavaScript, CSS, and static assets
- Auto-generated during the build process

## `/node_modules/` Directory

NPM/Yarn installed dependencies:

- Contains all third-party packages and their dependencies
- Managed automatically by package managers
- Excluded from version control via .gitignore

## `/prisma/` Directory

Database management and schema definition:

- **`schema.prisma`** - Prisma ORM schema definition with database models, relationships, and constraints
- **`seed.js`** - Database seeding script for populating initial data
- **`/migrations/`** - Database migration files for schema versioning and updates
  - **`migration_lock.toml`** - Migration lock file to prevent concurrent migrations
  - **`20260106120929_init/`** - Initial database schema migration
  - **`20260112085350_add_shop_model/`** - Migration adding shop/location model
  - **`20260113083128_update_saved_kit_products_to_json/`** - Migration updating saved kit data structure

## `/public/` Directory

Static assets served directly by the web server:

- **`manifest.json`** - Progressive Web App (PWA) manifest for mobile app-like experience
- **`sw.js`** - Service Worker for offline functionality and caching
- **`vite.svg`** - Vite logo/default favicon
- **`icon-192x192.png`** - PWA icon for mobile devices
- **`aheroo.png`** - Application logo or branding image
- **`1.jpg` through `6.jpg`** - Static image assets for UI components

## `/scripts/` Directory

Utility scripts for development and testing:

- **`style-check.js`** - Script to check and validate CSS/styling consistency
- **`theme-e2e.js`** - End-to-end testing script for theme functionality
- **`visual-check.js`** - Visual regression testing script
- **`visual-scan.js`** - Automated visual testing and screenshot generation

## `/server/` Directory

Backend Express.js application:

### `/server/controllers/` Directory

Business logic controllers handling API requests:

- **`adminController.js`** - Administrative operations (user management, system settings)
- **`authController.js`** - Authentication and authorization logic (login, registration, password reset)
- **`savedKitController.js`** - Saved product kits management for recurring orders

### `/server/cron/` Directory

Scheduled background jobs:

- **`geocode.js`** - Address geocoding job for location services
- **`geocodeManager.js`** - Manager for geocoding operations and queue handling
- **`notificationCleanup.js`** - Cleanup job for expired notifications
- **`reminders.js`** - Automated reminder system for orders and prescriptions

### `/server/db/` Directory

Database layer and utilities:

- **`client.js`** - Database client configuration and connection management
- **`integrityMiddleware.js`** - Database integrity checking middleware
- **`prisma.js`** - Prisma client initialization and configuration
- **`utilities.js`** - Database utility functions and helper methods

### `/server/events/` Directory

Event-driven architecture:

- **`commerceEventEmitter.js`** - Central event emitter for e-commerce events (stock updates, order changes, notifications)

### `/server/middleware/` Directory

Express middleware for request processing:

- **`auth.js`** - JWT authentication and token validation middleware
- **`chatbotSafety.js`** - Safety filters and content moderation for chatbot interactions
- **`errorHandler.js`** - Global error handling and response formatting
- **`isAdmin.js`** - Administrative role verification middleware
- **`rateLimiter.js`** - API rate limiting to prevent abuse
- **`roleAuth.js`** - Role-based access control middleware
- **`security.js`** - Security headers and protection middleware
- **`validation.js`** - Request validation middleware
- **`validationEnhanced.js`** - Enhanced validation with additional rules

## Summary

This Online24 Pharmacy project follows a modern full-stack architecture with:

- **Frontend**: React with Vite, Tailwind CSS, Zustand for state management
- **Backend**: Node.js/Express with Prisma ORM, PostgreSQL database
- **Features**: E-commerce functionality, prescription management, real-time notifications, admin panel
- **Architecture**: Modular structure with clear separation of concerns
- **Development**: Comprehensive testing, linting, and build optimization
- **Deployment**: PWA capabilities, service workers, and production-ready configuration

The project structure demonstrates enterprise-level organization with proper separation between frontend, backend, database, and configuration concerns.</content>
